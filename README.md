== Description ==

The Inventory Management Directory and Listings WordPress Plugin is a powerful tool designed for businesses, wholesalers, and e-commerce store owners who need to manage their products, stock levels, and directories efficiently. This plugin transforms your WordPress site into a comprehensive inventory management system with directory and listing capabilities. Users can add, edit, and categorize products or items, track stock quantities, and display them in an organized directory format. Perfect f

**Features:**

* Core functionality

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate via WordPress admin > Plugins
3. Configure via Settings > Inventory Management Directory and Listings WordPress Plugin
